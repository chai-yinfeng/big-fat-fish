大肥鱼语音对比

同一段中文，分别用小米 MiMo-V2.5-TTS 和微软 edge-tts 合成。文件就在本目录，直接用浏览器播放。

同一句：中性对比

文本：你好，我是大肥鱼。今天也要好好休息。

MiMo-V2.5-TTS 冰糖

WAV / 24kHz / 16-bit / 约 180 KB；首次实测约 4.6s（含网络和推理）

edge-tts Xiaoxiao

MP3 / 24kHz / 48kbps / 约 27 KB；首次实测约 0.6s

同一句：风格控制对比

文本：你回来啦。今天辛苦了，先坐下歇一会儿吧。

MiMo · 温柔

style：温柔、自然，像在跟亲近的人说话，语速稍慢

MiMo · 疲惫

style：声音有点疲惫，像是在深夜轻声说话，气声多一点，语速慢

edge · 放慢

edge 只能调 rate/pitch/volume；这里 rate=-10%

MiMo 音频标签

标签控制

文本：(轻笑)你回来啦。[叹气]今天辛苦了。 · style：自然口语，像日常聊天

走 DSH 适配器

adapter /companion/tts · voice=auto

x-tts-provider: mimo；同一个请求在没有 MiMo key 时会自动回退 edge。

怎么理解这组对比

维度MiMo-V2.5-TTSedge-tts
中文自然度高，语气更“有人味”中上，稳定但偏播音
风格/情绪自然语言指令 + 音频标签 + 导演模式基本只能调语速/音高/音量
音色冰糖/茉莉/苏打/白桦；可设计/克隆现成音色库
延迟非流式约 4–5s（本次实测）约 0.6s
文件WAV，体积大（约 180–300 KB/句）MP3，约 27–30 KB/句
成本限时免费（需 key）免费、无 key
适合陪伴、角色化、情绪表达兜底、低延迟、长文本

注意

  • 延迟是单次实测，包含网络和模型推理，不是稳定基准；流式接口会显著改善首包延迟。
  • MiMo 输出 WAV（24kHz 16-bit PCM），edge 输出 48kbps MP3；体积差异不代表音质差异，只影响传输/存储。
  • 正式体验上，建议“短句自动朗读用 MiMo，长文本/兜底用 edge”，或者直接只保留一个 provider。
